## 기능 요약

사용자가 컴퓨터 자판을 치거나 마우스를 크게 움직여 '컴퓨터 복귀 상태(Active)'가 감지되었을 때, 노아가 혼자 수면 치료 상태(`isSleeping = true`)에 잠겨있는 상황이라면 자동으로 깨어나도록 동적으로 기상 연동을 지원하는 기능입니다.

## 배경 / 필요 이유

현재 노아는 피로가 쌓여 자러 갔을 때(또는 유저 수동 Sleep 지시), 구체적인 클릭 방해를 하거나 피로도가 역치 이하(5 미만)로 줄어들 때까지 무조건 계속 잠을 잡니다. 
컴패니언의 핵심 목적은 **"사용자가 컴을 한참 쓰며 작업을 시작할 때 옆에서 깨어있어야 한다"**는 것입니다. 사용자가 활성 상태로 PC를 조작하기 시작했다면, 노아 역시 자율 흐름에 비례하여 동적으로 기상하여 일상을 공유하도록 돕는 유기성이 부족한 상태입니다.

## 상세 요구사항

1. [src/main/session/detector.ts](src/main/session/detector.ts) 및 OS 복귀 감지기(`onUserReturn` 이벤트 등) 발생 시점을 활용합니다.
2. 사용자의 마우스 조작, 키 입력 등으로 유저 복전 활성이 확인되는 순간, `state.isSleeping`이 참이라면 이를 즉각 `false`로 격하하여 깨웁니다.
3. 깰 때에는 "사용자로 인한 자율 기상" 상태이므로 적합한 기상 대사('...어, 왔어?') 및 수면 정지 메모리 이벤트를 동기 보존하여 메인에 가둡니다.

## 수락 기준 (Acceptance Criteria)

- [ ] 세션 검출기의 활동 리스너가 트리거될 때 잠 상태(`isSleeping`)가 즉시 종료된다.
- [ ] 잠에서 깼을 때 관련 기억 기록(`MemoryStore`)과 대사 출력이 발행된다.
- [ ] 동적 기상 변이 테스트 코드가 추가된다.
