## 기능 요약

메인 프로세스에서 10분 간격으로 생성되는 방 안의 오염물(`discomfortCount`, 최대 3개)을 단순 수치나 대사 징징거림으로만 알리지 않고, 사용자의 화면 공간을 실제로 가로막고 클릭(Raycast)을 방해하는 "디지털 글리치 이물질 3D 구체(Orb)" 형태로 렌더링하고 사용자가 직접 클릭하여 청소하는 인터랙션 연동을 완성합니다.

## 배경 / 필요 이유

현재 배설물 오염(Discomfort)은 10분 주기로 늘어나서 애정도 하강과 트라우마 증가라는 치명적인 파괴를 자행하고 있지만, 화면에서는 똥이나 얼룩 등 시각 요소가 전혀 없어 유저는 관계 파괴의 이유를 파악할 수 없습니다. 
그렇다고 더러운 똥 무더기 비주얼을 배치하는 것은 동기 방해를 유발하므로, 에이전트의 존재 의의인 디지털 세계 컨셉에 맞춰 **"오염을 지칭하는 글리치 구체"**를 띄우고 직접 클릭해 정화하게 만들어 놀이로서의 청소 목적을 확실히 강화하고자 합니다.

## 상세 요구사항

1. **글리치 구체 3D 렌더링**:
   - `discomfortCount`가 1 이상일 때, 방 공간 내에 "더러워 보이지 않으나 디지털 홀로그램 질감이 깨진 색상의 구체(Orb)"를 카운트 개수만큼 동적으로 생성 및 표시합니다.
   2. **화면 및 레이캐스트 점유 기믹**:
   - 이 구체들은 방 안의 아바타나 환경 앞을 가릴 뿐만 아니라, 3D `InteractionManager`에 정식 타겟으로 탑재됩니다.
   - 글리치가 차오르는 동안 사용자의 마우스 상호작용 레이캐스트를 스스로 흡수(가로막음)하여 수월한 노아과의 대화나 애무를 은은하게 "방해"합니다.
3. **클릭 및 청소 연동 IPC**:
   - 사용자가 화면을 가로막고 있는 디지털 글리치 구체를 직접 마우스로 "클릭"하면, 렌더러는 글리치 구체를 제거하고, 메인 프로세스로 `clean` Interaction Action(IPC)을 송신합니다.
   - 메인은 이를 통해 즉각 `discomfortCount` 수치를 제거하고 애정 상도를 회복하며 이물질이 깔끔하게 지워지는 파티클 정화 연동을 재생합니다.

## 수락 기준 (Acceptance Criteria)

- [ ] `discomfortCount` 개수(1~3)만큼 글리치 구체가 3D 방 씬 내에 노출된다.
- [ ] 글리치 구체가 아바타의 레이캐스트 인터랙션을 방해하며, 직접 클릭 시 사라진다.
- [ ] 클릭 제거 시 메인으로 `clean` IPC 신호가 전달되어 스탯이 정화되는 통합 유닛 테스트를 거친다.
